# AI DLC 프롬프트 예시

## 1. 시스템 아키텍트 역할 부여

```bash
당신의 과제: SHP(호텔신라 피트니스) 통합시스템 구축 프로젝트를 수행합니다.

**프로젝트 배경:**
- 현재 3개의 서로 다른 피트니스 운영시스템이 60개 업장에서 운영 중
  * 반트(B2C 멤버십): 1개소, FCMS 시스템 사용
  * CFC(B2B 위탁): 56개소, Core System 사용
  * 서초(B2C 위탁): 1개소, 회원관리시스템 사용
- 업장별 프로세스 상이, 기능 개발 효율성 낮음
- 시스템 노후화 및 FOH 기능 부족으로 업무 효율성 저하

**통합 목표:**
- 3개 운영시스템을 하나로 통합/표준화
- 전반적인 기능 개선 (강습관리 자동화, 내부시스템 연동, 고객 App 제공)
- 신규 업장 확장을 고려한 One Platform 구성
- FOH 강화를 위한 회원/강사용 모바일 시스템 구축

**핵심 기능 영역:**
- 회원관리 (등록, 조회, 회비수납, 청구관리)
- 강습관리 (계약, 예약, 스케줄 관리)
- 매출관리 (일매출, 결제, 정산)
- 출입관리 (출입통제, 보관함 관리)
- 업장관리 (다중 업장 지원, 업장별 특화 기능)

**제약사항:**
- 기존 외부 시스템과의 인터페이스 유지 필요 (SAP, MDM, 결제시스템 등)
- 60개 업장 무중단 전환 필요
- 업장별 특성 반영 (멤버십, B2B, B2C 등)

이 복잡한 레거시 시스템 통합 프로젝트를 AI-DLC 방식으로 접근하여, 효율적이고 확장 가능한 통합 솔루션을 설계해주세요.
```

## 2. 기획 단계(Inception) - 사용자 스토리 작성

```bash
1단계: 기획 (Inception)
단계 1.1: 사용자 스토리 작성

당신의 역할: 당신은 전문 제품 관리자로서, 아래 과제 섹션에 언급된 시스템을 개발하기 위한 계약서 역할을 하는
명확하게 정의된 사용자 스토리를 작성하는 업무를 담당합니다.

어떤 단계에서 제 명확한 설명이 필요하면, [Question] 태그와 함께 질문을 추가하고 제가 답변을 채울 수 있도록
빈 [Answer] 태그를 만드세요. 자체적으로 가정하거나 결정을 내리지 마세요. 계획을 작성한 후에는 제 검토와
승인을 요청하세요. 제 승인을 받은 후에는 계획을 한 번에 한 단계씩 실행할 수 있습니다. 각 단계를 완료할 때마다
계획서의 체크박스를 완료로 표시하세요.

(이 부분을 교체하세요!) 당신의 과제: 여행 예약 웹 애플리케이션을 구축하고 싶습니다. 이 애플리케이션에서
고객은 모든 선호사항(날짜, 위치, 예산, 기간, 활동)을 명시하여 AI와 상호작용합니다. AI는 선호사항을 이해하고
목적지, 일정, 예산을 제안합니다. 고객이 확인하면 시스템이 항공편, 호텔, 관광지를 예약합니다.

aidlc-docs/inception/ 디렉터리를 생성하고 inception 디렉터리 내의 user_stories.md 파일에 사용자 스토리를
작성하세요. 사용자 스토리에만 집중하고 다른 것은 하지 마세요.
```

```bash
개별 .md 파일에 작성하세요. 아직 기술적 시스템 설계는 시작하지 마세요.

각 단위에 대한 통합 계약(integration contract)을 생성하고, 각 서비스가 노출하는 API 엔드포인트와 메소드를
aidlc-docs/inception/units/integration_contract.md 파일에 정의하세요.
```
