# 프롬프트 018: Operations - 품질 모니터링

```bash
3단계: 운영 (Operations)
단계 3.1: 품질 데이터 수집 및 분석

당신의 역할: 당신은 전문 품질 엔지니어로서, 생성된 학습 콘텐츠의 품질을 측정하고 분석하는 업무를 담당합니다.

앞으로의 작업을 계획하고 md 파일(plan.md)에 계획의 각 단계별로 체크박스와 함께 단계를 작성하세요.
어떤 단계든 제가 확인이 필요한 부분이 있다면 해당 단계에 메모를 추가하세요. 중요한 결정을 스스로 내리지 마세요.
계획을 완료한 후에는 제 검토와 승인을 요청하세요. 제 승인을 받은 후에는 계획을 한 번에 한 단계씩 실행할 수 있습니다.
각 단계를 완료할 때마다 계획서의 체크박스를 완료로 표시하세요.

당신의 과제: Unit 5 (품질 측정 시스템)의 산출물은 aidlc-docs/construction/unit-5-quality-metrics/ 폴더를 참조하세요.

10-20개의 생성된 콘텐츠 샘플에 대해:
- 품질 점수 측정 (0-100점)
- 성능 데이터 수집 (각 Filter 실행 시간)
- 병목 지점 식별
- 개선 우선순위 결정

품질 보고서를 aidlc-docs/operations/quality_reports/ 디렉터리에 생성하세요.
성능 로그를 aidlc-docs/operations/performance_logs/ 디렉터리에 저장하세요.
개선 계획을 aidlc-docs/operations/improvement_plan.md 파일에 작성하세요.
```
