# Dashboard Unit

## 단위 개요

**책임**: 대시보드 조회, 생성, 편집, 삭제 및 위젯 배치 관리

**주요 목표**:

- 대시보드 CRUD 작업
- 대시보드 레이아웃과 위젯 배치
- 대시보드 공유 및 즐겨찾기 기능
- 반응형 디자인 지원
- 실시간 데이터 업데이트
- 플랜별 접근 제어

## 포함된 사용자 스토리

### US2.1: 대시보드 목록 조회

**As a** 사용자
**I want to** 내가 생성한 대시보드 목록을 볼 수 있기
**So that** 원하는 대시보드를 선택할 수 있다

**검증 기준**:

- Given: 사용자가 로그인한 상태
- When: 대시보드 페이지에 접속
- Then: 내가 생성한 대시보드 목록이 표시됨
- And: 각 대시보드의 이름, 설명, 카테고리, 수정일이 표시됨
- And: 최근 수정순, 이름순, 생성일순 정렬 옵션 제공
- And: 카테고리 필터 및 검색 기능 제공
- And: 내가 만든 것/즐겨찾기한 것 탭 분리
- And: 기본 대시보드가 있으면 버튼/배지 표시
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용

### US2.2: 대시보드 상세 보기

**As a** 사용자
**I want to** 선택한 대시보드의 위젯들과 데이터를 볼 수 있기
**So that** 경제 지표를 모니터링할 수 있다

**검증 기준**:

- Given: 대시보드를 선택한 상태
- When: 대시보드 상세 페이지 진입
- Then: 설정된 레이아웃대로 위젯들이 배치됨
- And: 조회 기간 선택 가능
- And: 뷰포트 내 위젯 우선 로드
- And: 스크롤 시 뷰포트 밖 위젯 점진적 로드
- And: 각 위젯이 실시간 데이터를 표시함
- And: US6.5에 정의된 플랜별 데이터 조회 기간 제한 적용

### US2.3: 공개 대시보드 탐색

**As a** 사용자
**I want to** 다른 사용자가 공개한 대시보드를 탐색하기
**So that** 유용한 대시보드를 발견하고 참고할 수 있다

**검증 기준**:

- Given: 로그인한 사용자
- When: 공개 대시보드 탐색 페이지 접속
- Then: 공개된 대시보드 목록 표시
- And: 각 대시보드의 이름, 설명, 카테고리, 작성자가 표시됨
- And: 인기순, 최신순 정렬 옵션 제공
- And: 카테고리 필터 및 검색 기능 제공
- And: 대시보드 미리보기 가능
- And: 즐겨찾기 및 복제 가능

### US2.4: 빈 대시보드 생성

**As a** 사용자
**I want to** 빈 대시보드를 생성하기
**So that** 처음부터 원하는 구성을 만들 수 있다

**검증 기준**:

- Given: 로그인한 사용자
- When: 빈 대시보드 생성 선택
- Then: 이름, 설명, 카테고리 입력 가능
- And: 공개/비공개 설정 선택 가능
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용

### US2.5: 템플릿에서 대시보드 생성

**As a** 사용자
**I want to** 템플릿을 사용하여 대시보드를 빠르게 생성하기
**So that** 처음부터 구성하지 않고 바로 사용할 수 있다

**검증 기준**:

- Given: 대시보드 생성시 템플릿 선택
- When: 원하는 템플릿 클릭
- Then: 템플릿 미리보기 표시
- And: 템플릿의 위젯 구성 확인 가능
- And: 템플릿 사용 시 대시보드 생성
- And: 생성된 대시보드는 템플릿 구성 그대로 복사
- And: 새 대시보드 이름, 설명 입력 가능
- And: 공개/비공개 설정 선택 가능
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용

### US2.6: 대시보드 복제

**As a** 사용자
**I want to** 기존 대시보드를 복제하기
**So that** 비슷한 구성의 새 대시보드를 빠르게 만들 수 있다

**검증 기준**:

- Given: 내 대시보드 또는 공개 대시보드 조회
- When: 복제 버튼 클릭
- Then: 새 대시보드 이름, 설명 입력
- And: 공개/비공개 설정 선택 가능
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용
- And: 대시보드와 모든 위젯 복사
- And: US6.5에 정의된 플랜별 위젯 수 제한 적용
- And: 복제 후 편집 가능

### US2.7: 대시보드 편집

**As a** 사용자
**I want to** 대시보드 정보와 레이아웃을 수정하기
**So that** 변경된 요구사항에 맞출 수 있다

**검증 기준**:

- Given: 대시보드 소유자
- When: 편집 모드 진입
- Then: 대시보드 이름, 설명, 카테고리 수정 가능
- And: 공개/비공개 설정 변경 가능
- And: 위젯 추가/제거/재배치 및 크기 조절 가능
- And: US6.5에 정의된 플랜별 대시보드당 위젯 수 제한 적용
- And: 편집 사항 저장 가능
- And: 자동 임시저장 기능 제공
- And: US6.5에 정의된 플랜별 버전 관리 기능 제공

### US2.8: 대시보드 삭제

**As a** 사용자
**I want to** 불필요한 대시보드를 삭제하기
**So that** 대시보드 목록을 정리할 수 있다

**검증 기준**:

- Given: 대시보드 소유자
- When: 삭제 버튼 클릭 후 확인
- Then: 대시보드 삭제
- And: 사용된 위젯은 삭제되지 않음

### US2.9: 대시보드 공유

**As a** 사용자
**I want to** 대시보드를 다른 사람과 공유하기
**So that** 정보를 함께 볼 수 있다

**검증 기준**:

- Given: 대시보드 소유자
- When: 공유 버튼 클릭
- Then: 공유 링크 생성
- And: 로그인 없이 웹에서 접근 가능
- And: 공유 페이지는 대시보드만 전체 화면으로 표시
- And: 소유자 플랜의 데이터 조회 기간 제한 적용
- And: SNS로 공유 가능
- And: 링크 복사 기능
- And: 공유 링크는 읽기 전용
- And: 링크 재생성 가능
- And: 회원가입 유도 UI 제공

### US2.10: 대시보드 즐겨찾기

**As a** 사용자
**I want to** 다른 사용자의 공개 대시보드를 즐겨찾기하기
**So that** 자주 참고하는 대시보드를 쉽게 접근할 수 있다

**검증 기준**:

- Given: 공개 대시보드 조회
- When: 즐겨찾기 버튼 클릭
- Then: 즐겨찾기 목록에 추가
- And: 즐겨찾기한 대시보드 탭에서 조회 가능
- And: 원본 대시보드 최신 상태 반영
- And: US6.5에 정의된 플랜별 즐겨찾기 수 제한 적용

### US2.11: 기본 대시보드 설정

**As a** 사용자
**I want to** 기본 대시보드를 설정하기
**So that** 로그인 시 원하는 대시보드를 바로 볼 수 있다

**검증 기준**:

- Given: 대시보드를 가진 사용자
- When: 프로필 설정 또는 대시보드 메뉴에서
- Then: 기본 대시보드로 설정 가능
- And: 설정하지 않으면 가장 최근에 본 대시보드가 기본
- And: 대시보드가 없으면 초기 가이드 표시

### US2.12: 대시보드 생성 시 법적 동의

**As a** 대시보드 작성자
**I want to** 대시보드 생성 시 법적 동의 사항을 확인하고
**So that** 투자 권고가 아님을 명확히 인지하고 법적 책임을 이해할 수 있다

**검증 기준**:

- Given: 로그인한 사용자가 대시보드 생성 시도
- When: 대시보드 생성 폼 제출
- Then: 필수 동의 체크박스 표시
- And: 다음 항목을 체크해야만 게시 가능:
  - "본인이 작성하는 대시보드는 개인 의견이며 투자 권고가 아닙니다"
  - "특정 종목의 직접적 매수/매도를 권유하지 않겠습니다"
  - "투자 손실에 대한 법적 책임이 없음을 이해합니다"
- And: 금지 사항 예시 명확히 표시:
  - ❌ "삼성전자 지금 사세요"
  - ❌ "100% 수익 보장"
  - ❌ "내일 급등 3종목"
- And: 위반 시 계정 제재 가능성 경고
- And: 동의 내역 로그로 저장 (userId, dashboardId, IP, User-Agent, timestamp)
- And: 동의 문구 버전 관리 (약관 변경 추적)

**기술 요구사항**:

- ConsentLog 저장 (법적 증거 확보)
- 3년 이상 로그 보관
- 동의 시점의 IP 주소 및 User-Agent 기록

### US2.13: 대시보드 조회 시 면책 조항

**As a** 대시보드 조회자
**I want to** 최초 조회 시 면책 조항을 확인하고
**So that** E-Torch가 정보 제공 플랫폼임을 명확히 인지할 수 있다

**검증 기준**:

- Given: 사용자의 최초 대시보드 조회
- When: 대시보드 페이지 진입
- Then: 면책 모달 표시 (1회만)
- And: 면책 내용 명확히 고지:
  - "E-Torch의 모든 대시보드는 작성자 개인의 분석 의견입니다"
  - "투자 권고가 아니며, E-Torch는 내용의 정확성을 보증하지 않습니다"
  - "투자 결정의 책임은 전적으로 이용자 본인에게 있습니다"
  - "투자에는 원금 손실 위험이 있습니다"
- And: "이해했으며, 다시 보지 않기" 체크박스 제공
- And: 동의 여부 로그 저장 (consentType: 'disclaimer_view')
- And: 모든 대시보드 하단에 간단한 면책 배너 고정 표시:
  - "ℹ️ 이 대시보드는 투자 권고가 아닙니다"

**UI/UX 요구사항**:

- 모달은 대시보드 내용을 가리지 않되, 반드시 확인해야 조회 가능
- 면책 배너는 눈에 띄되 사용자 경험 해치지 않도록

### US2.14: 대시보드 신고

**As a** 사용자
**I want to** 부적절한 투자 권유나 사기성 대시보드를 신고하고
**So that** 플랫폼 품질을 유지하고 다른 사용자를 보호할 수 있다

**검증 기준**:

- Given: 대시보드를 조회하는 사용자
- When: 신고 버튼 클릭
- Then: 신고 사유 선택 옵션 표시:
  - 투자 권유 (특정 종목 매수/매도 직접 추천)
  - 사기성 내용 (허위 정보, 수익 보장 주장)
  - 스팸/광고 (유료 시그널 서비스 홍보 등)
  - 기타 (상세 설명 입력)
- And: 신고 내역은 Admin Console로 전달
- And: 신고자 익명성 보장 (작성자에게 신고자 정보 비공개)
- And: 중복 신고 방지 (동일 사용자가 같은 대시보드 재신고 불가)
- And: 신고 완료 시 확인 메시지:
  - "신고가 접수되었습니다. 48시간 내 검토 예정입니다"

**비기능 요구사항**:

- 신고 내역 최소 1년 보관
- 악의적 신고 남용 방지 (과도한 신고 시 신고자 제재)

## 단위 간 의존성

### 입력 의존성

- Authentication Unit: 사용자 정보
- Subscription Unit: 플랜별 제한사항
- Widget Library Unit: 위젯 컴포넌트, 위젯 관리, 데이터 내보내기 (US3.8)
- Data Integration Unit: 데이터 페칭
- Admin Console Unit: 템플릿 목록, 카테고리 마스터

### 출력 제공

- 대시보드 뷰 렌더링
- 대시보드 메타데이터
- 레이아웃 정보
- 공유 링크
- 즐겨찾기 상태
- 위젯 상호작용 이벤트

## 보안 요구사항

- 대시보드 소유권이 검증되어야 한다
- 사용자별 대시보드 접근 권한이 검증되어야 한다
- 공유 링크가 읽기 전용으로 제한되어야 한다
- 법적 동의 로그가 안전하게 저장되어야 한다 (3년 이상)
- 동의 로그는 변조 불가능하도록 보호되어야 한다
- 신고 내역의 신고자 익명성이 보장되어야 한다
- 투자 권유성 콘텐츠가 자동 감지되어야 한다
