# Admin Console Unit

## 단위 개요

**책임**: 관리자 전용 기능 - 지표 관리, 사용자 관리, 템플릿 관리, 카테고리 관리

**주요 목표**:

- 경제 지표 등록 및 관리 - KOSIS/ECOS/OECD/CUSTOM 지원
- 카테고리 관리
- 수동 데이터 입력 및 관리
- 대시보드 템플릿 생성 및 관리
- 사용자 및 구독 관리
- 데이터 소스 관리 - 동적 추가 및 설정
- 플랜 제한 관리

## 포함된 사용자 스토리

### US6.1: 지표 등록

**As a** 관리자
**I want to** 새로운 경제 지표를 등록하기
**So that** 사용자가 해당 지표를 사용할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 지표 등록 폼 작성
- Then: 지표명, 설명, 출처 입력
- And: 소스 유형 선택: KOSIS, ECOS, OECD, CUSTOM
- And: 소스별 지표 탐색 및 선택
  - KOSIS: 키워드 검색 또는 계층 탐색
  - ECOS: 통계표 목록 → 세부 항목 선택
  - OECD: 데이터셋 목록에서 선택
  - CUSTOM: 등록된 지표 목록에서 선택
- And: 관리자가 사전 정의한 카테고리 선택

### US6.2: 지표 관리

**As a** 관리자
**I want to** 등록된 지표를 수정/삭제하기
**So that** 지표 정보를 최신으로 유지하고 외부 소스 파라미터 변경에 대응할 수 있다

**검증 기준**:

- Given: 등록된 지표
- When: 관리 페이지 접속
- Then: 지표 목록 표시
- And: 메타데이터 수정
- And: 원본 소스에서 API 파라미터 재탐색 및 갱신
- And: 삭제 가능
- And: 사용 통계 확인
- And: 연결 테스트 - API 호출 및 응답 시간 확인

### US6.3: 사용자 관리

**As a** 관리자
**I want to** 사용자 정보와 구독을 관리하기
**So that** 서비스를 효율적으로 운영하고 사용자 지원을 제공할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 사용자 관리 페이지 접속
- Then: 사용자 목록 조회
- And: 플랜 수동 변경 - Free ↔ Pro 전환 가능
- And: 변경 사유 입력 - 기존 사유 목록에서 선택 또는 직접 입력
- And: 만료일 설정 - 미설정 시 영구 변경, 설정 시 만료 후 자동 복원
- And: 사용자 활동 로그 조회 - 로그인, 대시보드 생성, 구독 변경 등
- And: 계정 활성화/비활성화 - 약관 위반, 어뷰징 대응 사유 기록

### US6.4: 데이터 소스 관리

**As a** 관리자
**I want to** 데이터 소스를 동적으로 관리하기
**So that** 새로운 데이터 제공자 추가 시 재배포 없이 즉시 대응할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 데이터 소스 관리 페이지 접속
- Then: 등록된 소스 목록 표시
- And: 새 데이터 소스 추가
- And: 소스별 API Key 관리 - 암호화 저장, 토글 방식 표시/숨김
- And: 소스 활성화/비활성화
- And: 소스별 연결 테스트 실행
- And: 변경 이력 기록

### US6.5: 플랜 제한 관리

**As a** 관리자
**I want to** 플랜별 제한사항을 동적으로 관리하기
**So that** 비즈니스 요구사항에 맞춰 즉시 조정할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 플랜 관리 페이지 접속
- Then: Free/Pro 플랜별 제한 목록 표시
- And: 제한값 수정 및 즉시 반영
- And: 플랜별 가격 설정 - 월간/연간 금액 및 통화 단위
- And: 새로운 제한 항목 추가
- And: 제한값별 적용 기간 설정 - 미설정 시 영구 적용
- And: 변경 이력 조회

### US6.6: 대시보드 템플릿 관리

**As a** 관리자
**I want to** 대시보드 템플릿을 생성하고 관리하기
**So that** 사용자에게 쉬운 시작점을 제공할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 템플릿 관리 페이지 접속
- Then: 새 템플릿 생성 가능
- And: 템플릿명, 설명, 카테고리 설정
- And: 기본 위젯 구성 및 배치
- And: 템플릿 활성화/비활성화
- And: 사용 통계 확인

### US6.7: 카테고리 관리

**As a** 관리자
**I want to** 지표 및 대시보드 카테고리를 생성하고 관리하기
**So that** 사용자가 일관된 카테고리로 콘텐츠를 분류할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 카테고리 관리 페이지 접속
- Then: 카테고리 목록 표시
- And: 새 카테고리 추가
- And: 카테고리 수정/삭제
- And: 카테고리별 사용 개수 표시
- And: 카테고리 순서 변경
- And: 카테고리 활성화/비활성화

### US6.8: 수동 데이터 입력 및 관리

**As a** 관리자
**I want to** API 없는 지표의 데이터를 수동으로 입력하고 관리하기
**So that** 외부 API가 제공하지 않는 중요 지표를 사용자에게 제공할 수 있다

**검증 기준**:

- Given: 관리자 권한 및 CUSTOM 소스 지표
- When: 수동 데이터 관리 페이지 접속
- Then: CUSTOM 소스 지표 선택 가능
- And: CSV 파일 업로드로 초기 데이터 등록
  - CSV 양식 다운로드
  - 업로드 전 데이터 검증
  - 미리보기 테이블 표시
  - 확인 후 일괄 저장
- And: 건당 데이터 입력
- And: 입력된 데이터 목록 조회
- And: 데이터 수정/삭제 및 변경 이력 기록

### US6.9: 신고된 컨텐츠 관리

**As a** 관리자
**I want to** 신고된 대시보드를 검토하고 적절한 조치를 취하여
**So that** 불법 투자 권유를 차단하고 플랫폼 품질을 유지할 수 있다

**검증 기준**:

- Given: 관리자 권한 및 신고 접수된 대시보드
- When: 컨텐츠 관리 페이지 접속
- Then: 신고된 대시보드 목록 조회
  - 신고 사유 (투자 권유, 사기, 스팸 등)
  - 신고 접수 일시 (최신순 정렬)
  - 신고자 수 (중복 신고 집계)
  - 대시보드 제목, 작성자, 내용 미리보기
  - 상태 (대기, 검토 중, 조치 완료)
- And: 대시보드 상세 검토
  - 원본 내용 전체 확인
  - 작성자 이력 조회 (이전 위반 내역)
  - 위반 여부 판단 근거 메모
- And: 조치 실행 옵션:
  - **경고**: 작성자에게 경고 메시지 발송 (1회 기록)
  - **삭제**: 대시보드 즉시 삭제 (복구 불가)
  - **계정 정지**: 작성자 게시 제한 (48시간)
  - **무혐의**: 신고 각하 (사유 기록)
- And: 조치 사유 필수 기록
  - 어떤 부분이 문제인지 구체적 명시
  - 작성자와 신고자에게 결과 통보
- And: 조치 내역 ActivityLog에 자동 기록

**비기능 요구사항**:

- 신고 접수 후 48시간 내 1차 검토
- 조치 내역 영구 보관 (법적 분쟁 대비)

### US6.10: 컨텐츠 위반 사용자 관리

**As a** 관리자
**I want to** 위반 이력이 누적된 사용자를 관리하여
**So that** 반복 위반자를 효과적으로 제재할 수 있다

**검증 기준**:

- Given: 관리자 권한
- When: 사용자 위반 관리 페이지 접속
- Then: 사용자별 위반 이력 조회
  - 경고 횟수 (누적)
  - 삭제된 대시보드 수
  - 마지막 위반 날짜
  - 누적 신고 수 (정당한 신고만 집계)
  - 위반 유형별 분류 (투자 권유, 사기, 스팸)
- And: 단계적 제재 시스템 자동 적용:
  - **1회 경고**: 이메일 + 앱 내 알림
  - **2회 경고**: 48시간 게시 제한
  - **3회 위반**: 계정 영구 정지
- And: 수동 제재 옵션
  - 관리자 판단으로 즉시 정지
  - 제재 사유 상세 기록
- And: 제재 내역 사용자에게 통보
  - 위반 사유, 제재 기간, 이의 제기 방법
- And: 제재 내역 ActivityLog 기록

**비기능 요구사항**:

- 제재 이력 영구 보관
- 이의 제기 시 재검토 프로세스

### US6.11: 위험 컨텐츠 자동 탐지

**As a** 관리자
**I want to** 위험 키워드가 포함된 대시보드를 자동으로 플래깅하여
**So that** 문제 콘텐츠를 빠르게 발견하고 대응할 수 있다

**검증 기준**:

- Given: 관리자 권한 및 자동 탐지 시스템 운영
- When: 자동 탐지 결과 페이지 접속
- Then: 매일 자동 스캔 실행 (신규/수정 대시보드 대상)
- And: 위험 패턴 탐지:
  - 특정 종목명 + 행동 유도 ("삼성전자 사세요")
  - 수익 보장 표현 ("100% 수익", "반드시 오른다")
  - 타이밍 단정 ("내일 급등", "곧 폭등")
  - 외부 유료 서비스 링크 ("텔레그램", "카톡방")
- And: 플래깅된 대시보드 목록
  - 탐지된 키워드 하이라이트 표시
  - 위험도 점수 (높음/중간/낮음)
  - 작성자 정보 및 이전 위반 이력
- And: 자동 조치 설정 (선택 사항):
  - **높음**: 즉시 비공개 + 작성자 알림
  - **중간**: 검토 대기열 추가
  - **낮음**: 로그만 기록, 공개 유지
- And: 오탐 처리
  - 관리자가 "문제 없음" 판정 가능
  - 오탐으로 판정된 패턴 학습 (재탐지 방지)

**기술 요구사항**:

- 키워드 룰 엔진 (정규표현식 기반)
- 탐지 룰 버전 관리 (언제든 수정 가능)
- 일일 배치 스케줄러

## 기술적 요구사항

### Micro Frontend Architecture 구조

E-Torch는 두 개의 독립 Next.js 애플리케이션으로 구성됩니다:

```
apps/
  web/              ← User Dashboard
  admin/            ← Admin Console
packages/
  ui/               ← 공유 UI 컴포넌트
  core/             ← 공유 타입, 유틸리티
  query/            ← 공유 데이터 레이어
  data-sources/     ← 공유 외부 API 클라이언트
  charts/           ← 공유 차트 컴포넌트
```

**Admin Console 특성:**

- Next.js 15 + React 19 기반 단일 앱
- User Dashboard와 독립 배포
- Supabase Auth 기반 공통 인증
- Role 기반 접근 제어 - admin 역할 확인
- packages/ 를 통한 코드 공유

**주요 페이지:**

- `/indicators` - 지표 관리
- `/users` - 사용자 관리
- `/templates` - 템플릿 관리
- `/data-sources` - 데이터 소스 관리
- `/plan-limits` - 플랜 제한 관리
- `/categories` - 카테고리 관리
- `/custom-data` - 수동 데이터 관리
- `/reports` - 신고 관리 (US6.9)
- `/violations` - 위반 사용자 관리 (US6.10)
- `/content-detection` - 자동 탐지 관리 (US6.11)

### 의존성

- **입력 의존성**:
  - Authentication Unit: 사용자 인증 및 역할 확인

- **출력 제공**:
  - 지표 메타데이터
  - 대시보드 템플릿
  - 카테고리 마스터
  - 플랜 제한 설정

## 보안 요구사항

- 관리자 역할이 인증 시 검증되어야 한다
- 관리자 페이지 접근 시 권한이 재검증되어야 한다
- 일반 사용자는 관리자 기능에 접근할 수 없어야 한다
- 관리자의 모든 작업이 감사 로그로 기록되어야 한다
- 민감한 작업 수행 시 재인증이 요구되어야 한다
- API Key가 암호화되어 저장되어야 한다
- API Key 접근이 로그로 기록되어야 한다
- 신고 내역의 신고자 정보가 보호되어야 한다 (익명성 보장)
- 위반 로그 및 제재 내역이 영구 보존되어야 한다
- 컨텐츠 자동 탐지 시스템이 오탐을 최소화해야 한다
- 대시보드 삭제 조치 시 복구 불가능함을 관리자에게 재확인해야 한다
