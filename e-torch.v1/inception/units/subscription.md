# Subscription Unit

## 단위 개요

**책임**: 구독 플랜 관리, 결제 처리, 플랜별 제한사항 적용

**현재 범위**:

- Free/Pro 플랜 관리
- 플랜별 기능 제한 적용
- 구독 상태 관리
- 사용량 추적 및 알림
- DB 기반 플랜 업그레이드 및 취소

**향후 확장**:

- 외부 결제 게이트웨이 통합

## 포함된 사용자 스토리

### US5.1: 구독 정보 조회

**As a** 일반 사용자
**I want to** 내 구독 정보를 확인하기
**So that** 현재 플랜과 혜택을 파악할 수 있다

**검증 기준**:

- Given: 구독 관리 페이지 접속
- When: 구독 정보를 조회하면
- Then: 현재 플랜 표시: Free 또는 Pro
- And: 플랜 시작일 표시
- And: Pro 플랜인 경우 만료일 표시

### US5.2: 사용량 현황 확인

**As a** 일반 사용자
**I want to** 내 리소스 사용량을 확인하기
**So that** 플랜 제한에 얼마나 근접했는지 알 수 있다

**검증 기준**:

- Given: 구독 관리 페이지 또는 대시보드에서
- When: 사용량 섹션을 확인하면
- Then: 대시보드 사용량을 현재 개수와 최대 개수로 표시
- And: 위젯 사용량을 현재 개수와 최대 개수로 표시
- And: 즐겨찾기 사용량을 현재 개수와 최대 개수로 표시
- And: 제한 도달 시 시각적 경고 표시
- And: 각 항목별 사용률 표시

### US5.3: 플랜 업그레이드

**As a** Free 플랜 사용자
**I want to** Pro 플랜으로 업그레이드하기
**So that** 고급 기능을 사용할 수 있다

**검증 기준**:

- Given: 구독 관리 페이지에서
- When: Pro 플랜 업그레이드 버튼 클릭
- Then: 플랜 비교 및 가격 정보 표시
- And: 결제 주기 선택: 월간 또는 연간
- And: 결제 페이지로 이동
- And: 결제 완료 후 Pro 기능 즉시 활성화
- And: 제한 해제 확인 메시지 표시

### US5.4: 제한 도달 시 업그레이드 안내

**As a** Free 플랜 사용자
**I want to** 제한 도달 시 업그레이드 안내를 받기
**So that** 필요한 경우 플랜을 변경할 수 있다

**검증 기준**:

- Given: Free 플랜으로 리소스 생성 시도
- When: 플랜 제한 초과 시
- Then: 친화적인 에러 메시지 표시
- And: 현재 사용량과 최대 허용량 표시
- And: Pro 플랜의 주요 혜택 안내
- And: 업그레이드 버튼 제공
- And: "나중에" 옵션 제공

### US5.5: 구독 취소

**As a** Pro 플랜 사용자
**I want to** 구독을 취소하기
**So that** 플랜을 변경할 수 있다

**검증 기준**:

- Given: 구독 관리 페이지에서
- When: 구독 취소 버튼 클릭
- Then: 취소 시 영향 안내: 남은 구독 기간과 기능 제한 사항
- And: 취소 확인 메시지
- And: 현재 구독 기간 만료까지 Pro 기능 유지
- And: 만료 후 Free 플랜으로 자동 전환

## 플랜별 제한사항

관리자가 Admin Console을 통해 동적으로 변경 가능하며, 아래는 초기 기본값입니다.

### Free 플랜

- 대시보드: 최대 3개
- 위젯: 대시보드당 최대 6개
- 데이터 조회: 최근 3년
- 버전 관리: 불가
- 즐겨찾기: 최대 10개

### Pro 플랜

- 대시보드: 무제한
- 위젯: 무제한
- 데이터 조회: 전체 기간
- 버전 관리: 최근 10개 버전
- 즐겨찾기: 무제한

## 동적 플랜 제한 관리

플랜별 제한사항은 관리자 페이지(US6.5)에서 동적으로 관리됩니다:

- DB에서 플랜별 제한값을 조회하여 적용
- 관리자가 제한값 변경 시 즉시 반영

## 단위 간 의존성

### 입력 의존성

- **Authentication Unit**: 사용자 ID 및 인증 상태
- **Admin Console Unit**: 플랜별 제한 설정값 (US6.5)

### 출력 제공

다른 Unit에서 사용 가능한 기능 (상세 인터페이스는 integration_contract.md 참조):

- **모든 Unit에 제공**:
  - 권한 검증 기능
    - 대시보드 생성 가능 여부 확인
    - 위젯 추가 가능 여부 확인
    - 데이터 조회 기간 검증
    - 버전 복원 가능 여부 확인
    - 즐겨찾기 추가 가능 여부 확인
  - 구독 정보 조회
    - 사용자별 현재 플랜 조회
    - 플랜별 동적 제한값 조회
  - 사용량 통계 조회
    - 리소스별 현재 사용량 확인
    - 플랜 제한 도달 여부 확인

- **Dashboard Unit에 제공**:
  - 플랜 변경 기능
    - Pro 플랜 업그레이드 처리
    - 구독 취소 처리

## 제한사항 적용 시점

### 리소스 생성/수정 시 검증

- **대시보드 생성**: 현재 생성 개수 확인
- **위젯 추가**: 대시보드별 위젯 수 확인
- **버전 복원**: Pro 플랜 전용 기능 확인
- **데이터 조회**: 조회 가능 기간 확인
- **즐겨찾기 추가**: 즐겨찾기 개수 확인

### 권한 검증 흐름

1. 사용자 구독 정보 조회
2. DB에서 플랜별 동적 제한값 조회
3. 현재 사용량 확인
4. 제한 초과 여부 판단
5. 제한 초과 시 업그레이드 안내

## 보안 요구사항

- 구독 상태가 서버에서 검증되어야 한다
- 클라이언트에서 플랜 제한을 우회할 수 없어야 한다
- 결제 정보가 암호화되어 저장되어야 한다
- API 호출 시 권한이 검증되어야 한다
