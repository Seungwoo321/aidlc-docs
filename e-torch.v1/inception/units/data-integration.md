# Data Integration Unit

## 단위 개요

**책임**: 외부 API 호출, 데이터 변환, 표준화 및 캐싱 관리

**주요 목표**:
- Supabase Edge Functions 활용
- 외부 API 통합: KOSIS, ECOS, OECD
- 데이터 포맷 표준화
- 효율적인 캐싱 전략

## 포함된 사용자 스토리

### US4.1: 다중 데이터 소스 통합

**As a** 사용자
**I want to** KOSIS, ECOS, OECD 등 다양한 출처의 지표를 사용하기
**So that** 풍부한 데이터로 분석할 수 있다

**검증 기준**:
- Given: 관리자가 다양한 출처의 지표를 등록한 상태
- When: 위젯에서 지표 데이터를 요청
- Then: 출처에 관계없이 표준화된 포맷으로 데이터 제공
- And: 각 출처의 고유한 API 파라미터 자동 처리
- And: KOSIS, ECOS, OECD, CUSTOM 소스 지원
- And: 데이터 주기 정보 포함: 일별, 월별, 분기별, 연간
- And: 메타데이터 함께 제공: 단위, 설명, 최종 업데이트 시각

### US4.2: 데이터 로딩 성능 최적화

**As a** 사용자
**I want to** 지표 데이터가 빠르게 로드되기
**So that** 대기 시간 없이 대시보드를 볼 수 있다

**검증 기준**:
- Given: 위젯이 데이터를 요청하는 상태
- When: 동일한 데이터를 다시 요청
- Then: 캐시된 데이터를 우선 제공
- And: 외부 API 호출 최소화
- And: 여러 위젯이 동일 지표를 사용할 때 한 번만 조회
- And: 배치 페칭으로 다중 지표를 효율적으로 조회
- And: 캐시 만료 시 백그라운드에서 갱신

### US4.3: 데이터 가용성 보장

**As a** 사용자
**I want to** 외부 API 장애 시에도 최근 데이터를 볼 수 있기
**So that** 안정적으로 서비스를 이용할 수 있다

**검증 기준**:
- Given: 외부 API에 장애가 발생한 상태
- When: 위젯이 데이터를 요청
- Then: 캐시된 최근 데이터 제공
- And: 데이터가 캐시임을 표시
- And: 최종 업데이트 시각 표시
- And: API 복구 시 자동으로 최신 데이터 갱신
- And: 에러 로깅 및 재시도 로직 동작

## 단위 간 의존성

### 입력 의존성

- **Authentication Unit**: 사용자 인증 및 세션 관리
- **Subscription Unit**: 플랜별 데이터 조회 기간 제한
- **Admin Console Unit**: 등록된 지표 메타데이터

### 출력 제공

다른 Unit에서 사용 가능한 기능 - 상세 인터페이스는 integration_contract.md 참조:

- **Widget Library Unit에 제공**:
  - 지표 데이터 조회
    - 지표 ID로 최신 데이터 조회
    - 기간 지정 데이터 조회
    - 실시간 데이터 갱신
  - 지표 검색 및 선택
    - 키워드 검색
    - 카테고리별 필터링
    - 지표 메타데이터 조회

- **Dashboard Unit에 제공**:
  - 캐시된 데이터 조회
  - 배치 데이터 페칭
  - 데이터 스트림 구독

## 보안 요구사항

- API Key가 안전하게 관리되어야 한다
- 외부 API 요청 파라미터가 검증되어야 한다
- 과도한 API 요청이 제한되어야 한다
- 승인된 출처에서만 접근 가능해야 한다
