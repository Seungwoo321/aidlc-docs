# E-Torch AI DLC 프롬프트

## 1. 데이터 시각화 전문가 역할 부여

```bash
당신의 과제: E-Torch 경제 지표 대시보드 시스템을 구축하는 프로젝트를 수행합니다.

**프로젝트 배경:**
- 현재 개발 진행 중인 경제 지표 대시보드 프로젝트를 Clean Architecture로 전환 중
- 기존 컴포넌트 기반 구조에서 도메인 중심의 확장 가능한 아키텍처로 마이그레이션
- 월별, 분기별, 연간 단위의 경제 지표를 모니터링하고 시각화하는 대시보드 시스템 필요
- Next.js API Route를 통해 외부 데이터 소스를 호출하고 공통 포맷으로 변환
- Supabase로 사용자 인증, 구독 정보, API 파라미터 설정을 관리
- 사용자 맞춤형 대시보드와 인터랙티브한 차트 제공
- 통계 기반 데이터 분석 및 시각화 제공

**프로젝트 목표:**
- Clean Architecture 기반의 확장 가능한 대시보드 플랫폼 구축
- 주기적인 경제 지표 데이터 처리 및 시각화 시스템 구현
- 재사용 가능한 차트 컴포넌트 라이브러리 개발
- 다양한 경제 지표 데이터 소스 통합 및 관리
- 사용자 대시보드와 관리자 콘솔 분리 아키텍처 구축

**핵심 기능 영역:**
- 데이터 통합 (외부 API 호출, 데이터 포맷 변환, 표준화)
- 차트 라이브러리 (시계열, 막대, 파이, 히트맵 등)
- 대시보드 관리 (위젯 배치, 사용자 정의, 템플릿)
- 데이터 분석 (통계 분석, 추세 분석, 비교 분석)
- 관리자 콘솔 (사용자 관리, 구독 관리, 데이터 소스 설정, API 파라미터 관리)
- 사용자/구독 관리 (Supabase 기반 인증, 구독 플랜)

**기술 스택:**
- Framework: Next.js (App Router)
- UI: React, TypeScript, Tailwind CSS
- 차트: Recharts
- 상태관리: Redux Toolkit, React Query
- Database/Auth: Supabase (사용자 인증, 구독 관리, API 파라미터 관리)
- 모노레포: pnpm workspace, turborepo

이 대시보드 프로젝트를 AI-DLC 방식으로 접근하여, 모듈화되고 확장 가능한 데이터 시각화 솔루션을 설계해주세요.
```
