# Widget Library Unit

## 단위 개요

**책임**: 위젯 도메인 로직 관리 및 차트 시각화 컴포넌트 제공

**주요 목표**:

- 위젯 생성, 편집, 복사, 삭제
- 위젯 시각화 컴포넌트 제공: 차트 7종, 텍스트 2종
- 위젯 팩토리 패턴 구현
- 공개/비공개 위젯 관리
- **위젯 라이브러리-대시보드 아키텍처**:
  - 위젯 라이브러리: 위젯 원본 저장소
  - 대시보드: 위젯 라이브러리의 위젯 참조
  - 공개 위젯 추가 시: 복사하여 내 라이브러리에 저장 후 참조
- **위젯은 파라미터만 저장**, 실제 데이터는 Data Integration Unit에서 조회

**렌더링 책임 범위**:

- ✅ Widget Library: 차트/텍스트 위젯 컴포넌트 제공
- ✅ Dashboard Unit: 위젯 배치 및 레이아웃 관리

## 포함된 사용자 스토리

### US3.1: 위젯 생성

**As a** 사용자
**I want to** 새로운 위젯을 생성하기
**So that** 원하는 지표를 시각화할 수 있다

**검증 기준**:

- Given: 로그인한 사용자
- When: 위젯 생성 버튼 클릭
- Then: 위젯 타입 선택
- And: 지표 검색 및 선택
- And: 시각화 옵션 설정
- And: 생성된 위젯 설정이 내 위젯 라이브러리에 저장된다
- And: 대시보드 편집 중 생성 시 현재 대시보드에 자동 배치

### US3.2: 위젯 편집

**As a** 위젯 소유자
**I want to** 위젯 설정을 수정하기
**So that** 표시 방식을 변경할 수 있다

**검증 기준**:

- Given: 위젯 소유자
- When: 위젯 편집 모드 진입
- Then: 지표 변경 가능
- And: 시각화 옵션 변경 가능
- And: 편집 중 미리보기 기간 선택 가능
- And: 변경사항 즉시 미리보기
- And: 변경사항이 위젯 라이브러리에 저장된다
- And: 해당 위젯을 사용하는 모든 대시보드에 즉시 반영된다

### US3.3: 공개 위젯 추가

**As a** 일반 사용자
**I want to** 공개된 위젯을 내 대시보드에 추가하기
**So that** 다른 사용자가 만든 위젯을 활용할 수 있다

**검증 기준**:

- Given: 로그인한 사용자
- When: 공개 위젯 선택 및 추가
- Then: 원본 설정을 복사한 새 위젯 생성
- And: 새 위젯이 내 위젯 라이브러리에 저장된다
- And: 선택한 대시보드에 배치된다
- And: 복사된 위젯은 독립적으로 편집 가능하다
- And: Free 플랜은 대시보드당 위젯 6개 제한 체크

### US3.4: 내 위젯을 다른 대시보드에 배치

**As a** 일반 사용자
**I want to** 내 위젯을 다른 대시보드에도 배치하기
**So that** 하나의 위젯을 여러 대시보드에서 활용할 수 있다

**검증 기준**:

- Given: 내 위젯 라이브러리
- When: 위젯을 다른 대시보드에 추가
- Then: 대시보드 선택 및 위젯 배치
- And: 위젯 편집 시 해당 위젯을 사용하는 모든 대시보드에 자동 반영
- And: Free 플랜은 대시보드당 위젯 6개 제한 체크

### US3.5: 내 위젯 라이브러리 관리

**As a** 사용자
**I want to** 내 위젯을 한 곳에서 관리하기
**So that** 위젯을 효율적으로 조회하고 정리할 수 있다

**검증 기준**:

- Given: 로그인한 사용자
- When: "내 위젯" 페이지 접근
- Then: 내가 생성한 모든 위젯 목록 표시
- And: 위젯 타입별 필터링 가능
- And: 지표별 필터링 가능
- And: 위젯별 사용 중인 대시보드 수 확인 가능
- And: 공개/비공개 상태 토글 가능
- And: 위젯 편집 및 삭제 가능
- And: "새 위젯 만들기" 버튼 제공

### US3.6: 위젯 삭제

**As a** 위젯 소유자
**I want to** 불필요한 위젯을 삭제하기
**So that** 위젯 목록을 정리할 수 있다

**검증 기준**:

- Given: 위젯 소유자
- When: 위젯 삭제 선택
- Then: 사용 중인 대시보드 확인 및 표시
- And: 삭제 경고 메시지 표시
- And: 삭제 확인 시 위젯 라이브러리에서 삭제
- And: 해당 위젯을 사용하는 모든 대시보드에서 자동 제거

### US3.7: 공개 위젯 갤러리 탐색

**As a** 사용자
**I want to** 다른 사용자가 공개한 위젯을 탐색하기
**So that** 유용한 위젯을 발견하고 활용할 수 있다

**검증 기준**:

- Given: 로그인한 사용자
- When: "공개 위젯 갤러리" 페이지 접근
- Then: 공개된 모든 위젯 목록 표시
- And: 인기 위젯 Top 10 섹션 제공
- And: 카테고리별 탐색 가능
- And: 위젯 타입별 필터링 가능
- And: 지표별 필터링 가능
- And: 키워드 검색 가능
- And: 위젯 미리보기 가능
- And: "내 대시보드에 추가" 버튼 제공

### US3.8: 데이터 내보내기

**As a** Pro 플랜 사용자
**I want to** 차트 데이터를 CSV/Excel로 내보내기
**So that** 외부 도구에서 추가 분석을 수행할 수 있다

**검증 기준**:

- Given: 차트 위젯이 데이터를 표시하고 있을 때
- When: 내보내기 버튼 클릭
- Then: CSV 또는 Excel 형식 선택 가능
- And: 선택한 형식으로 데이터 다운로드
- And: 파일명에 위젯명과 날짜 포함
- And: 현재 표시된 기간의 데이터만 내보내기
- And: Free 플랜 사용자에게는 기능 비활성화 및 업그레이드 안내

## 위젯 타입

### 지원하는 9가지 위젯 타입

**차트 위젯:**

1. **Time Series Chart** (`time-series`): 시계열 데이터 추세 분석
2. **Bar Chart** (`bar-chart`): 카테고리별 비교
3. **Pie Chart** (`pie-chart`): 구성비 표시
4. **Treemap** (`treemap`): 계층적 구성비 시각화
5. **Scatter Chart** (`scatter-chart`): 상관관계 분석
6. **Radar Chart** (`radar-chart`): 다차원 데이터 비교
7. **Radial Bar Chart** (`radial-bar-chart`): 방사형 막대 차트

**텍스트 위젯:**
8. **Text Custom** (`text-custom`): 사용자 정의 텍스트 위젯
9. **Text Data** (`text-data`): 데이터 수치 강조 위젯

## 단위 간 의존성

### 입력 의존성

- **Authentication Unit**: 사용자 인증 및 권한 확인
- **Subscription Unit**: 플랜별 제한사항 확인
- **Data Integration Unit**: 실시간 데이터 조회

### 출력 제공

- **Dashboard Unit에 제공**:
  - 9가지 차트/텍스트 위젯 컴포넌트
  - 위젯 렌더링 인터페이스
  - 위젯 메타데이터
  - 위젯 생성/편집/삭제 기능
  - 위젯 복사 기능
  - 공개/비공개 위젯 관리
