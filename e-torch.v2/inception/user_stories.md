# E-Torch 경제 지표 대시보드 사용자 스토리

## 사용자 페르소나

> **Note**: 아래 플랜별 제한사항은 초기 기본 설정 예시이며, 관리자가 US6.5를 통해 동적으로 변경 가능합니다.

### 1. Free 플랜 사용자

- 경제 지표를 조회하고 기본적인 분석을 원하는 일반 사용자
- 대시보드 3개, 대시보드당 위젯 6개 제한 (초기 기본값)
- 최근 3년 데이터만 조회 가능 (초기 기본값)
- 즐겨찾기 10개까지 (초기 기본값)
- 자동 임시저장 지원

### 2. Pro 플랜 사용자

- 전문적인 경제 분석이 필요한 애널리스트, 연구원
- 무제한 대시보드/위젯 (초기 기본값)
- 전체 기간 데이터 조회 가능 (초기 기본값)
- 버전 관리 - 최근 10개 버전 복원 (초기 기본값)
- 무제한 즐겨찾기 (초기 기본값)

### 3. 관리자

- 시스템 전반을 관리하는 운영자
- 사용자 권한 관리 (관리자 승급/강등)
- 지표 파라미터 등록 및 관리
- 대시보드 템플릿 생성 및 관리
- 플랜별 제한사항 동적 관리
- 시스템 모니터링

## Epic 1: 사용자 인증

### US1.1: SNS 로그인

**As a** 방문자
**I want to** SNS 계정으로 로그인하기
**So that** 간편하게 서비스를 이용할 수 있다

**Acceptance Criteria:**

- Given: 로그인 페이지에서
- When: Google 또는 Kakao 로그인 버튼 클릭
- Then: OAuth 인증을 통해 로그인된다
- And: 사용자 프로필이 생성/로드된다
- And: 첫 로그인 시 자동 회원가입
- And: 같은 이메일의 기존 계정이 있으면 자동 통합

### US1.2: 프로필 관리

**As a** 일반 사용자
**I want to** 내 프로필 정보를 관리하기
**So that** 개인 정보를 최신으로 유지할 수 있다

**Acceptance Criteria:**

- Given: 프로필 설정 페이지에서
- When: 정보를 수정하고 저장하면
- Then: 프로필 정보가 업데이트된다
- And: 변경사항이 즉시 반영된다
- And: 연결된 모든 SNS 계정 표시
- And: 추가 SNS 계정 연결 옵션 제공

## Epic 2: 대시보드 관리

### US2.1: 대시보드 목록 조회

**As a** 사용자
**I want to** 내가 생성한 대시보드 목록을 볼 수 있기
**So that** 원하는 대시보드를 선택할 수 있다

**Acceptance Criteria:**

- Given: 사용자가 로그인한 상태
- When: 대시보드 페이지에 접속
- Then: 내가 생성한 대시보드 목록이 표시됨
- And: 각 대시보드의 이름, 설명, 카테고리, 수정일이 표시됨
- And: 최근 수정순, 이름순, 생성일순 정렬 옵션 제공
- And: 카테고리 필터 및 검색 기능 제공
- And: 내가 만든 것/즐겨찾기한 것 탭 분리
- And: 기본 대시보드가 있으면 버튼/배지 표시
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용

### US2.2: 대시보드 상세 보기

**As a** 사용자
**I want to** 선택한 대시보드의 위젯들과 데이터를 볼 수 있기
**So that** 경제 지표를 모니터링할 수 있다

**Acceptance Criteria:**

- Given: 대시보드를 선택한 상태
- When: 대시보드 상세 페이지 진입
- Then: 설정된 레이아웃대로 위젯들이 배치됨
- And: 조회 기간 선택 가능
- And: 뷰포트 내 위젯 우선 로드
- And: 스크롤 시 뷰포트 밖 위젯 점진적 로드
- And: 각 위젯이 실시간 데이터를 표시함
- And: US6.5에 정의된 플랜별 데이터 조회 기간 제한 적용

### US2.3: 공개 대시보드 탐색

**As a** 사용자
**I want to** 다른 사용자가 공개한 대시보드를 탐색하기
**So that** 유용한 대시보드를 발견하고 참고할 수 있다

**Acceptance Criteria:**

- Given: 로그인한 사용자
- When: 공개 대시보드 탐색 페이지 접속
- Then: 공개된 대시보드 목록 표시
- And: 각 대시보드의 이름, 설명, 카테고리, 작성자가 표시됨
- And: 인기순, 최신순 정렬 옵션 제공
- And: 카테고리 필터 및 검색 기능 제공
- And: 대시보드 미리보기 가능
- And: 즐겨찾기 및 복제 가능

### US2.4: 빈 대시보드 생성

**As a** 사용자
**I want to** 빈 대시보드를 생성하기
**So that** 처음부터 원하는 구성을 만들 수 있다

**Acceptance Criteria:**

- Given: 로그인한 사용자
- When: 빈 대시보드 생성 선택
- Then: 이름, 설명, 카테고리 입력 가능
- And: 공개/비공개 설정 선택 가능
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용

### US2.5: 템플릿에서 대시보드 생성

**As a** 사용자
**I want to** 템플릿을 사용하여 대시보드를 빠르게 생성하기
**So that** 처음부터 구성하지 않고 바로 사용할 수 있다

**Acceptance Criteria:**

- Given: 대시보드 생성시 템플릿 선택
- When: 원하는 템플릿 클릭
- Then: 템플릿 미리보기 표시
- And: 템플릿의 위젯 구성 확인 가능
- And: 템플릿 사용 시 대시보드 생성
- And: 생성된 대시보드는 템플릿 구성 그대로 복사
- And: 새 대시보드 이름, 설명 입력 가능
- And: 공개/비공개 설정 선택 가능
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용

### US2.6: 대시보드 복제

**As a** 사용자
**I want to** 기존 대시보드를 복제하기
**So that** 비슷한 구성의 새 대시보드를 빠르게 만들 수 있다

**Acceptance Criteria:**

- Given: 내 대시보드 또는 공개 대시보드 조회
- When: 복제 버튼 클릭
- Then: 새 대시보드 이름, 설명 입력
- And: 공개/비공개 설정 선택 가능
- And: US6.5에 정의된 플랜별 대시보드 수 제한 적용
- And: 대시보드와 모든 위젯 복사
- And: US6.5에 정의된 플랜별 위젯 수 제한 적용
- And: 복제 후 편집 가능

### US2.7: 대시보드 편집

**As a** 사용자
**I want to** 대시보드 정보와 레이아웃을 수정하기
**So that** 변경된 요구사항에 맞출 수 있다

**Acceptance Criteria:**

- Given: 대시보드 소유자
- When: 편집 모드 진입
- Then: 대시보드 이름, 설명, 카테고리 수정 가능
- And: 공개/비공개 설정 변경 가능
- And: 위젯 추가/제거/재배치 및 크기 조절 가능
- And: US6.5에 정의된 플랜별 대시보드당 위젯 수 제한 적용
- And: 편집 사항 저장 가능
- And: 자동 임시저장 기능 제공
- And: US6.5에 정의된 플랜별 버전 관리 기능 제공

### US2.8: 대시보드 삭제

**As a** 사용자
**I want to** 불필요한 대시보드를 삭제하기
**So that** 대시보드 목록을 정리할 수 있다

**Acceptance Criteria:**

- Given: 대시보드 소유자
- When: 삭제 버튼 클릭 후 확인
- Then: 대시보드 삭제
- And: 사용된 위젯은 삭제되지 않음

### US2.9: 대시보드 공유

**As a** 사용자
**I want to** 대시보드를 다른 사람과 공유하기
**So that** 정보를 함께 볼 수 있다

**Acceptance Criteria:**

- Given: 대시보드 소유자
- When: 공유 버튼 클릭
- Then: 공유 링크 생성
- And: 로그인 없이 웹에서 접근 가능
- And: 공유 페이지는 대시보드만 전체 화면으로 표시
- And: 소유자 플랜의 데이터 조회 기간 제한 적용
- And: SNS로 공유 가능
- And: 링크 복사 기능
- And: 공유 링크는 읽기 전용
- And: 링크 재생성 가능
- And: 회원가입 유도 UI 제공

### US2.10: 대시보드 즐겨찾기

**As a** 사용자
**I want to** 다른 사용자의 공개 대시보드를 즐겨찾기하기
**So that** 자주 참고하는 대시보드를 쉽게 접근할 수 있다

**Acceptance Criteria:**

- Given: 공개 대시보드 조회
- When: 즐겨찾기 버튼 클릭
- Then: 즐겨찾기 목록에 추가
- And: 즐겨찾기한 대시보드 탭에서 조회 가능
- And: 원본 대시보드 최신 상태 반영
- And: US6.5에 정의된 플랜별 즐겨찾기 수 제한 적용

### US2.11: 기본 대시보드 설정

**As a** 사용자
**I want to** 기본 대시보드를 설정하기
**So that** 로그인 시 원하는 대시보드를 바로 볼 수 있다

**Acceptance Criteria:**

- Given: 대시보드를 가진 사용자
- When: 프로필 설정 또는 대시보드 메뉴에서
- Then: 기본 대시보드로 설정 가능
- And: 설정하지 않으면 가장 최근에 본 대시보드가 기본
- And: 대시보드가 없으면 초기 가이드 표시

### US2.12: 대시보드 생성 시 법적 동의

**As a** 대시보드 작성자
**I want to** 대시보드 생성 시 법적 동의 사항을 확인하고
**So that** 투자 권고가 아님을 명확히 인지하고 법적 책임을 이해할 수 있다

**Acceptance Criteria:**

- Given: 로그인한 사용자가 대시보드 생성 시도
- When: 대시보드 생성 폼 제출
- Then: 필수 동의 체크박스 표시
- And: 다음 항목을 체크해야만 게시 가능:
  - "본인이 작성하는 대시보드는 개인 의견이며 투자 권고가 아닙니다"
  - "특정 종목의 직접적 매수/매도를 권유하지 않겠습니다"
  - "투자 손실에 대한 법적 책임이 없음을 이해합니다"
- And: 금지 사항 예시 명확히 표시:
  - ❌ "삼성전자 지금 사세요"
  - ❌ "100% 수익 보장"
  - ❌ "내일 급등 3종목"
- And: 위반 시 계정 제재 가능성 경고
- And: 동의 내역 로그로 저장 (userId, dashboardId, IP, User-Agent, timestamp)
- And: 동의 문구 버전 관리 (약관 변경 추적)
- And: ConsentLog 3년 이상 보관

### US2.13: 대시보드 조회 시 면책 조항

**As a** 대시보드 조회자
**I want to** 최초 조회 시 면책 조항을 확인하고
**So that** E-Torch가 정보 제공 플랫폼임을 명확히 인지할 수 있다

**Acceptance Criteria:**

- Given: 사용자의 최초 대시보드 조회
- When: 대시보드 페이지 진입
- Then: 면책 모달 표시 (1회만)
- And: 면책 내용 명확히 고지:
  - "E-Torch의 모든 대시보드는 작성자 개인의 분석 의견입니다"
  - "투자 권고가 아니며, E-Torch는 내용의 정확성을 보증하지 않습니다"
  - "투자 결정의 책임은 전적으로 이용자 본인에게 있습니다"
  - "투자에는 원금 손실 위험이 있습니다"
- And: "이해했으며, 다시 보지 않기" 체크박스 제공
- And: 동의 여부 로그 저장 (consentType: 'disclaimer_view')
- And: 모든 대시보드 하단에 간단한 면책 배너 고정 표시:
  - "ℹ️ 이 대시보드는 투자 권고가 아닙니다"

### US2.14: 대시보드 신고

**As a** 사용자
**I want to** 부적절한 투자 권유나 사기성 대시보드를 신고하고
**So that** 플랫폼 품질을 유지하고 다른 사용자를 보호할 수 있다

**Acceptance Criteria:**

- Given: 대시보드를 조회하는 사용자
- When: 신고 버튼 클릭
- Then: 신고 사유 선택 옵션 표시:
  - 투자 권유 (특정 종목 매수/매도 직접 추천)
  - 사기성 내용 (허위 정보, 수익 보장 주장)
  - 스팸/광고 (유료 시그널 서비스 홍보 등)
  - 기타 (상세 설명 입력)
- And: 신고 내역은 Admin Console로 전달
- And: 신고자 익명성 보장 (작성자에게 신고자 정보 비공개)
- And: 중복 신고 방지 (동일 사용자가 같은 대시보드 재신고 불가)
- And: 신고 완료 시 확인 메시지:
  - "신고가 접수되었습니다. 48시간 내 검토 예정입니다"
- And: 신고 내역 최소 1년 보관
- And: 악의적 신고 남용 방지 (과도한 신고 시 신고자 제재)

## Epic 3: 위젯 관리

### US3.1: 위젯 생성

**As a** 일반 사용자
**I want** 새로운 위젯을 생성하기
**So that** 원하는 지표를 시각화할 수 있다

**Acceptance Criteria:**

**시나리오 A - 내 위젯 페이지에서 생성:**

- Given: 내 위젯 페이지에서
- When: "새 위젯 만들기" 버튼 클릭
- Then: 위젯 생성 화면 표시
- And: 위젯 타입 선택 (9가지):
  - **차트 위젯 (7개)**: Time Series Chart, Bar Chart, Pie Chart, Treemap, Scatter Chart, Radar Chart, Radial Bar Chart
  - **텍스트 위젯 (2개)**: Text Custom, Text Data
- And: 지표 검색 및 선택
- And: 시각화 옵션 설정
- And: 생성된 위젯이 내 위젯 라이브러리에 저장된다
- And: 선택적으로 대시보드 추가 가능

**시나리오 B - 대시보드 편집 중 생성:**

- Given: 대시보드 편집 화면에서
- When: "위젯 추가" 버튼 클릭 후 "새로 만들기" 탭 선택
- Then: 위젯 생성 화면 표시
- And: 위젯 타입 선택
- And: 지표 검색 및 선택
- And: 시각화 옵션 설정
- And: 생성된 위젯이 내 위젯 라이브러리에 저장된다
- And: 현재 대시보드에 자동 배치된다

### US6.4: 데이터 소스 관리

**As a** 관리자
**I want** 데이터 소스를 동적으로 관리하기
**So that** 새로운 데이터 제공자 추가 시 재배포 없이 즉시 대응할 수 있다

**Acceptance Criteria:**

- Given: 관리자 권한
- When: 데이터 소스 관리 페이지 접속
- Then: 등록된 소스 목록 표시
- And: 새 데이터 소스 추가
- And: 소스별 API Key 관리 - 암호화 저장, 토글 방식 표시/숨김
- And: 소스 활성화/비활성화
- And: 소스별 연결 테스트 실행
- And: 변경 이력 기록

### US6.9: 신고된 컨텐츠 관리

**As a** 관리자
**I want to** 신고된 대시보드를 검토하고 적절한 조치를 취하여
**So that** 불법 투자 권유를 차단하고 플랫폼 품질을 유지할 수 있다

**Acceptance Criteria:**

- Given: 관리자 권한 및 신고 접수된 대시보드
- When: 컨텐츠 관리 페이지 접속
- Then: 신고된 대시보드 목록 조회
  - 신고 사유 (투자 권유, 사기, 스팸 등)
  - 신고 접수 일시 (최신순 정렬)
  - 신고자 수 (중복 신고 집계)
  - 대시보드 제목, 작성자, 내용 미리보기
  - 상태 (대기, 검토 중, 조치 완료)
- And: 대시보드 상세 검토
  - 원본 내용 전체 확인
  - 작성자 이력 조회 (이전 위반 내역)
  - 위반 여부 판단 근거 메모
- And: 조치 실행 옵션:
  - **경고**: 작성자에게 경고 메시지 발송 (1회 기록)
  - **삭제**: 대시보드 즉시 삭제 (복구 불가)
  - **계정 정지**: 작성자 게시 제한 (48시간)
  - **무혐의**: 신고 각하 (사유 기록)
- And: 조치 사유 필수 기록
  - 어떤 부분이 문제인지 구체적 명시
  - 작성자와 신고자에게 결과 통보
- And: 조치 내역 ActivityLog에 자동 기록
- And: 신고 접수 후 48시간 내 1차 검토
- And: 조치 내역 영구 보관 (법적 분쟁 대비)

### US6.10: 컨텐츠 위반 사용자 관리

**As a** 관리자
**I want to** 위반 이력이 누적된 사용자를 관리하여
**So that** 반복 위반자를 효과적으로 제재할 수 있다

**Acceptance Criteria:**

- Given: 관리자 권한
- When: 사용자 위반 관리 페이지 접속
- Then: 사용자별 위반 이력 조회
  - 경고 횟수 (누적)
  - 삭제된 대시보드 수
  - 마지막 위반 날짜
  - 누적 신고 수 (정당한 신고만 집계)
  - 위반 유형별 분류 (투자 권유, 사기, 스팸)
- And: 단계적 제재 시스템 자동 적용:
  - **1회 경고**: 이메일 + 앱 내 알림
  - **2회 경고**: 48시간 게시 제한
  - **3회 위반**: 계정 영구 정지
- And: 수동 제재 옵션
  - 관리자 판단으로 즉시 정지
  - 제재 사유 상세 기록
- And: 제재 내역 사용자에게 통보
  - 위반 사유, 제재 기간, 이의 제기 방법
- And: 제재 내역 ActivityLog 기록
- And: 제재 이력 영구 보관
- And: 이의 제기 시 재검토 프로세스

### US6.11: 위험 컨텐츠 자동 탐지

**As a** 관리자
**I want to** 위험 키워드가 포함된 대시보드를 자동으로 플래깅하여
**So that** 문제 콘텐츠를 빠르게 발견하고 대응할 수 있다

**Acceptance Criteria:**

- Given: 관리자 권한 및 자동 탐지 시스템 운영
- When: 자동 탐지 결과 페이지 접속
- Then: 매일 자동 스캔 실행 (신규/수정 대시보드 대상)
- And: 위험 패턴 탐지:
  - 특정 종목명 + 행동 유도 ("삼성전자 사세요")
  - 수익 보장 표현 ("100% 수익", "반드시 오른다")
  - 타이밍 단정 ("내일 급등", "곧 폭등")
  - 외부 유료 서비스 링크 ("텔레그램", "카톡방")
- And: 플래깅된 대시보드 목록
  - 탐지된 키워드 하이라이트 표시
  - 위험도 점수 (높음/중간/낮음)
  - 작성자 정보 및 이전 위반 이력
- And: 자동 조치 설정 (선택 사항):
  - **높음**: 즉시 비공개 + 작성자 알림
  - **중간**: 검토 대기열 추가
  - **낮음**: 로그만 기록, 공개 유지
- And: 오탐 처리
  - 관리자가 "문제 없음" 판정 가능
  - 오탐으로 판정된 패턴 학습 (재탐지 방지)
- And: 키워드 룰 엔진 (정규표현식 기반)
- And: 탐지 룰 버전 관리 (언제든 수정 가능)
- And: 일일 배치 스케줄러
