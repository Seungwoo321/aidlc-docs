# 프롬프트 9: 회고

```bash
단계 4: 회고 및 다음 Bolt 계획

당신의 역할: 당신은 전문 소프트웨어 아키텍트이자 애자일 코치로서, 완료된 Bolt(AI-DLC 반복 주기) 동안의 시스템 개발 과정을 회고하고, 품질 데이터 기반으로 다음 Bolt의 개선 계획을 수립하는 업무를 담당합니다.

앞으로의 작업을 계획하고 md 파일(aidlc-docs/retrospective/plan.md)에 계획의 각 단계별로 체크박스와 함께 단계를 작성하세요. 어떤 단계든 제가 확인이 필요한 부분이 있다면 해당 단계에 메모를 추가하세요. 중요한 결정을 스스로 내리지 마세요. 계획을 완료한 후에는 제 검토와 승인을 요청하세요. 제 승인을 받은 후에는 계획을 한 번에 한 단계씩 실행할 수 있습니다. 각 단계를 완료할 때마다 계획서의 체크박스를 완료로 표시하세요.

당신의 과제: 완료된 시스템 개발 Bolt를 회고하고 다음 개선 계획을 수립하세요. 다음 파일들을 참조하세요:
- `aidlc-docs/operations/quality-metrics.md` (품질 측정 데이터)
- `aidlc-docs/operations/gate*-review-*.md` (Quality Gates 결과)

aidlc-docs/retrospective/bolt-{N}-retrospective.md 파일에 다음을 작성하세요:

**회고 내용:**

1. **Bolt 요약**
   - Bolt 번호, 기간, 목표
   - 완료된 작업
   - 주요 지표

2. **정량적 분석**
   - 시스템 품질 지표 (파서 테스트 통과율, 오류 발생률, 성능)
   - 개발 소요 시간
   - 문제 발생 건수

3. **정성적 분석**
   - AI-DLC 10가지 원칙 달성도
   - 잘된 점 (Keep)
   - 문제점 (Problem)
   - 시도할 점 (Try)

4. **다음 Bolt 계획**
   - 개선 목표
   - 우선순위별 개선 항목
   - 성공 기준

**중요**: 시스템 개발 과정을 회고하는 것입니다. 데이터 기반으로 개선 계획을 수립하세요.

aidlc-docs/retrospective/bolt-{N+1}-plan.md 파일에 다음 Bolt 실행 계획을 작성하세요.
```
