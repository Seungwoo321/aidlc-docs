# 프롬프트 8: Operations - 시스템 품질 측정

```bash
단계 3.2: 시스템 품질 측정 방법 정의

당신의 역할: 당신은 전문 품질 보증 엔지니어로서, 콘텐츠 생성 시스템의 품질을 측정하는 방법을 설계하고, 시스템 효과성을 모니터링하는 시스템을 구축하는 업무를 담당합니다.

앞으로의 작업을 계획하고 md 파일(aidlc-docs/operations/plan.md)에 계획의 각 단계별로 체크박스와 함께 단계를 작성하세요. 어떤 단계든 제가 확인이 필요한 부분이 있다면 해당 단계에 메모를 추가하세요. 중요한 결정을 스스로 내리지 마세요. 계획을 완료한 후에는 제 검토와 승인을 요청하세요. 제 승인을 받은 후에는 계획을 한 번에 한 단계씩 실행할 수 있습니다. 각 단계를 완료할 때마다 계획서의 체크박스를 완료로 표시하세요.

당신의 과제: 콘텐츠 생성 시스템의 품질을 측정하는 방법을 설계하세요.

aidlc-docs/operations/quality-metrics.md 파일에 다음을 작성하세요:

**측정 대상:**
- 생성된 콘텐츠 품질 (파서 테스트 통과율)
- 시스템 안정성 (오류 발생률)
- 시스템 성능 (생성 시간)
- 에이전트 핸드오프 성공률

**품질 지표 정의:**
1. 파서 테스트 통과율 (목표: 100%)
2. 오류 발생률 (목표: <5%)
3. 평균 생성 시간 (토픽당, 목표: <5분)
4. 핸드오프 성공률 (목표: 100%)
5. 재시도 횟수 (목표: <1회)

**측정 방법:**
- 자동 테스트 스크립트 실행
- 로그 분석
- 통계 수집 및 대시보드

**개선 루프:**
측정 → 분석 → 개선 → 재측정

필요하다면 실제 측정 스크립트를 작성하세요.
```
