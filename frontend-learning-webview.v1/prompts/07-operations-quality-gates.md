# 프롬프트 7: Operations - Quality Gates

```bash
3단계: 운영 (Operations)
단계 3.1: Quality Gates 구현

당신의 역할: 당신은 전문 품질 보증 엔지니어로서, 시스템 개발 과정에 Quality Gates(인간 검증 포인트)를 구현하고, 시스템 개선 워크플로를 통합하는 업무를 담당합니다.

앞으로의 작업을 계획하고 md 파일(aidlc-docs/operations/plan.md)에 계획의 각 단계별로 체크박스와 함께 단계를 작성하세요. 어떤 단계든 제가 확인이 필요한 부분이 있다면 해당 단계에 메모를 추가하세요. 중요한 결정을 스스로 내리지 마세요. 계획을 완료한 후에는 제 검토와 승인을 요청하세요. 제 승인을 받은 후에는 계획을 한 번에 한 단계씩 실행할 수 있습니다. 각 단계를 완료할 때마다 계획서의 체크박스를 완료로 표시하세요.

당신의 과제: 시스템 개발 과정에 Quality Gates를 정의하고 구현하세요.

aidlc-docs/operations/quality-gates.md 파일에 다음을 작성하세요:

**Quality Gates 정의:**

**Gate 1: 설계 검토**
- 위치: Filter 계약 + Pipe 메커니즘 설계 완료 후
- 검증 항목: Filter 계약 문서 완성도, Pipe 메커니즘 설계 명확성, 일관성
- 체크리스트 작성

**Gate 2: 구현 검증**
- 위치: 에이전트 프롬프트 개선 + 오케스트레이션 개선 완료 후
- 검증 항목: 파일럿 테스트 (샘플 콘텐츠 생성), 파서 테스트 통과, 핸드오프 검증
- 체크리스트 작성

**Gate 3: 배포 승인**
- 위치: 전체 시스템 통합 완료 후
- 검증 항목: 문서화 완료, 롤백 계획, 최종 승인
- 체크리스트 작성

**중요**: 시스템 개발 단계의 검증 포인트입니다. 콘텐츠 생성 자동화는 유지됩니다.

aidlc-docs/operations/quality-gates-checklist.md 파일에 실제 체크리스트 템플릿을 작성하세요.
```
